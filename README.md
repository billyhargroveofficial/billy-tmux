# billy-tmux

Личная конфигурация tmux. Основной файл — [`.tmux.conf`](.tmux.conf),
а скрипты и список имён для окон и сессий лежат в [`.config/tmux`](.config/tmux).

## Подключение

Разместить репозиторий в `~/billy-tmux` и связать его файлы с домашним каталогом:

```sh
ln -s ~/billy-tmux/.tmux.conf ~/.tmux.conf
mkdir -p ~/.config
ln -s ~/billy-tmux/.config/tmux ~/.config/tmux
```

Если эти пути уже заняты, сначала сохранить существующие файлы отдельно.
Применить изменения в работающем tmux: `tmux source-file ~/.tmux.conf` либо
`Ctrl+A`, затем `r`.

## Основные клавиши

Префикс — `Ctrl+A`.

| Действие | Клавиши после префикса |
| --- | --- |
| Сплит вниз | `-` |
| Сплит вправо | `_` (`Shift+-`) |
| Фокус между пейнами | стрелки |
| Изменить размер пейна | `Shift+стрелки` |
| Новое окно | `c` |
| Перезагрузить конфиг | `r` |

Для оформления строки состояния нужен шрифт с символами Powerline/Nerd Font.
Внешних tmux-плагинов нет.
